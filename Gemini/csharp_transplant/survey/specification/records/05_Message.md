## Message (Opcode: 0x05)

Messageレコードは、特定のチャンネル上の単一のタイムスタンプ付きメッセージをエンコードします。 メッセージのエンコーディングとスキーマは、そのメッセージが属するチャンネルIDに対応するChannelレコードの定義と一致しなければなりません。

### フィールド

| フィールド名 | データ型 | 説明 |
|---|---|---|
| `channel_id` | `uint16` | このメッセージが属するチャンネルの一意なIDです。 |
| `sequence` | `uint32` | メッセージの欠落を検出するためのオプションのカウンターです。 パブリッシャーが提供するシーケンス番号を使用するか、レコーダーで割り当てるか、不要な場合は0に設定します。 |
| `log_time` | `uint64` | メッセージが記録された時刻（ナノ秒単位のエポックタイム）。 |
| `publish_time` | `uint64` | メッセージが公開された時刻（ナノ秒単位のエポックタイム）。 利用できない場合は、`log_time`と同じ値を設定する必要があります。 |
| `data` | `bytes` | メッセージデータ本体です。 このデータは、チャンネルのスキーマに従ってデコードされる必要があります。 |
