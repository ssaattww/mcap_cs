# タスク 4.1: 適合性テストの実施

## 概要
プロジェクトルートの `tests/conformance` にあるテストスイートを使用して、C#実装がMCAP仕様に準拠していることを確認します。

## 手順
1.  `tests/conformance` ディレクトリの構造とテストデータの利用方法を理解します。
2.  C#から適合性テストを実行するためのスクリプトまたはテストハーネスを開発します。これは、既存のMCAPファイル（`tests/conformance` 内のファイルなど）を読み込み、C#ライブラリで処理し、結果を検証するものです。
3.  適合性テストを実行し、C#実装がMCAP仕様に準拠していることを確認します。
4.  テストが失敗した場合は、原因を特定し、C#ライブラリの修正を行います。

## 完了条件
-   C#から適合性テストを実行できる環境が構築されている。
-   適合性テストがすべてパスし、C#実装がMCAP仕様に準拠していることが確認されている。
-   プロジェクトが正常にビルドできる。
