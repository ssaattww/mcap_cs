# C++ MCAPライブラリの機能

C++版のMCAPライブラリは、MCAPファイルの読み書きを行うための包括的な機能を提供します。以下は、`mcap/reader.hpp`および`mcap/writer.hpp`ヘッダーファイルから抽出した主要な機能の一覧です。

## データモデル

MCAPファイルフォーマットの各レコードタイプに対応する構造体が定義されています。これらはMCAPファイルの論理的な構成要素を表します。

- **`Record`**: 全てのレコードの基本となる汎用的なTLV(Type-Length-Value)構造体。
- **`Header`**: ファイルの先頭に置かれ、プロファイル情報などを含む。
- **`Footer`**: ファイルの末尾に置かれ、サマリーセクションへのオフセットなどを含む。
- **`Schema`**: メッセージのスキーマ定義。
- **`Channel`**: メッセージが属するチャンネル（トピック）の情報。
- **`Message`**: 実際のメッセージデータ。
- **`Attachment`**: 添付ファイル。
- **`Metadata`**: メタデータ。
- **`Chunk`**: メッセージなどをまとめたチャンク。
- **`MessageIndex`**: メッセージインデックス。
- **`ChunkIndex`**: チャンクインデックス。
- **`AttachmentIndex`**: 添付ファイルインデックス。
- **`MetadataIndex`**: メタデータインデックス。
- **`Statistics`**: ファイル全体の統計情報。
- **`SummaryOffset`**: サマリーオフセット情報。
- **`DataEnd`**: データセクションの終わりを示す。
- **`MessageView`**: 読み込み時に返される、メッセージとその関連情報（スキーマ、チャンネル）への参照を保持するビュー。

## 基本型とユーティリティ

ライブラリ全体で使用される基本的な型定義や列挙型です。

- **`Status`**: 操作の成功・失敗を示すステータス。
- **`OpCode`**: MCAPレコードの種類を識別するための列挙型。
- **`Compression`**: サポートされている圧縮アルゴリズム（None, Lz4, Zstd）の列挙型。
- **`CompressionLevel`**: 圧縮レベルの列挙型。
- **`ReadSummaryMethod`**: サマリーの読み込み方法を指定する列挙型。
- **`ReadMessageOptions`**: メッセージ読み込み時のオプション（時間範囲、トピックフィルタ等）を保持する構造体。
- **`McapWriterOptions`**: MCAP書き込み時のオプション（チャンクサイズ、圧縮設定等）を保持する構造体。

## 書き込み機能 (`McapWriter`)

`McapWriter`クラスは、MCAPファイルを生成するためのインターフェースを提供します。

- **ファイル/ストリームへの書き込み**: `open()`メソッドにより、ファイルパス (`std::string_view`) または `IWritable` を実装したカスタムライター（例: `StreamWriter`）への書き込みが可能です。
- **スキーマとチャンネルの登録**: `addSchema()` と `addChannel()` で、メッセージの型定義とトピックを登録します。
- **メッセージの書き込み**: `write(const Message&)` で、シリアライズされたメッセージをファイルに書き込みます。
- **アタッチメントとメタデータの追加**: `write(Attachment&)` と `write(const Metadata&)` で、ファイルに添付ファイルやメタデータを追加できます。
- **チャンク化と圧縮**: 
    - パフォーマンス向上のため、メッセージはチャンクにまとめて書き込まれます。
    - `McapWriterOptions` でチャンクサイズ (`chunkSize`) を設定できます。
    - 圧縮アルゴリズムとして **Zstd** と **LZ4** をサポートしており、圧縮レベルも指定可能です (`compression`, `compressionLevel`)。
    - チャンク化や圧縮を無効にするオプション (`noChunking`, `forceCompression`) も提供されています。
- **インデックス生成**: 
    - 効率的なデータアクセスのため、メッセージインデックスとチャンクインデックスを自動的に生成します。
    - これらのインデックスはサマリーセクションに書き込まれ、読み込み時の高速なシークを可能にします。
    - インデックス生成を無効化するオプション (`noMessageIndex`, `noChunkIndex`) も利用できます。
- **CRCチェック**: データ破損を検出するため、チャンクやレコードのCRCチェックを有効/無効にできます (`noChunkCRC`, `enableDataCRC`)。
- **柔軟な設定**: `McapWriterOptions` 構造体を通じて、プロファイル設定、ライブラリ情報、サマリーセクションの有無など、書き込み動作を細かく制御できます。

## 読み込み機能 (`McapReader`)

`McapReader`クラスは、MCAPファイルからデータを効率的に読み込むための機能を提供します。

- **ファイル/ストリームからの読み込み**: `open()`メソッドにより、ファイルパス (`std::string_view`)、`std::ifstream`、または `IReadable` を実装したカスタムリーダーからの読み込みが可能です。
- **サマリーの解析**: `readSummary()` を呼び出すことで、ファイルの末尾にあるサマリーセクションを解析し、インデックス情報をメモリにロードします。これにより、メッセージへの高速なランダムアクセスが可能になります。
- **メッセージのイテレーション**: 
    - `readMessages()` は、ファイル内のメッセージを反復処理するための `LinearMessageView` を返します。
    - **時間範囲フィルタ**: `startTime` と `endTime` を指定して、特定の時間範囲のメッセージのみを読み込めます。
    - **トピックフィルタ**: `topicFilter` ラムダ式を渡すことで、特定のトピックのメッセージのみを選択できます。
    - **ソート順序**: メッセージをファイル内の物理的な順序 (`FileOrder`)、ログ時刻順 (`LogTimeOrder`)、または逆順 (`ReverseLogTimeOrder`) で読み込むことができます。
- **データへのアクセス**: 
    - `header()`, `footer()`, `statistics()` で、ファイルのヘッダー、フッター、統計情報にアクセスできます。
    - `channels()` と `schemas()` で、ファイルに登録されている全てのチャンネルとスキーマの情報を取得できます。
    - `chunkIndexes()`, `metadataIndexes()`, `attachmentIndexes()` で、対応するインデックス情報にアクセスできます。
- **低レベルアクセス**: `IReadable` や `RecordReader` などの低レベルインターフェースも提供されており、より細かい制御が必要な高度なユースケースに対応します。
- **圧縮解除**: ZstdまたはLZ4で圧縮されたチャンクを自動的に伸長します。

## 低レベルインターフェースと拡張性

- **`IReadable`/`IWritable`**: ファイル以外のデータソース（例: ネットワークストリーム、メモリバッファ）を扱うための抽象インターフェースです。
- **`ICompressedReader`/`IChunkWriter`**: 圧縮/伸長のロジックをカプセル化し、カスタム圧縮アルゴリズムの追加を容易にします。
- **`RecordReader`/`TypedRecordReader`**: MCAPレコードレベルでの直接的な読み込みと解析を可能にし、特殊な解析ツールやカスタムリーダーの実装をサポートします。

## Internalユーティリティ

ライブラリ内部で利用される、シリアライズ/デシリアライズ、文字列操作、CRC計算などのためのヘルパー関数やクラス群です。これらは通常、ライブラリの利用者が直接使用することはありません。

## 外部ライブラリ依存

C++ MCAPライブラリは、特定の機能を実現するために以下の外部ライブラリに依存しています。

- **[zstd](https://facebook.github.io/zstd/)**: チャンクデータの圧縮および伸長のために使用される高圧縮率のライブラリです。`McapWriter` で `Compression::Zstd` を指定した場合や、Zstdで圧縮されたファイルを `McapReader` で読み込む際に利用されます。
- **[lz4](https://lz4.github.io/lz4/)**: 高速な圧縮および伸長を実現するために使用されるライブラリです。`McapWriter` で `Compression::Lz4` を指定した場合や、LZ4で圧縮されたファイルを読み込む際に利用されます。

これらの依存関係は、`MCAP_COMPRESSION_NO_ZSTD` や `MCAP_COMPRESSION_NO_LZ4` といったプリプロセッサマクロを定義することで、必要に応じて無効化することも可能です。
