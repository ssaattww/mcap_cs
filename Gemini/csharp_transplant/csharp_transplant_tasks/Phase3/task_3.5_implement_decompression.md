# タスク 3.5: 圧縮解除機能の実装

## 概要
ZstdまたはLZ4で圧縮されたチャンクを自動的に伸長する機能を実装します。

## 手順
1.  フェーズ2で導入した `ZstdNet` および `lz4net` (または同等のライブラリ) を使用します。
2.  `McapReader` クラスに、チャンクデータを読み込む際に、チャンクヘッダーの `Compression` フィールドに基づいて適切な伸長アルゴリズムを適用するロジックを追加します。
3.  `ICompressedReader` に相当するインターフェースを設計し、伸長ロジックを抽象化することも検討します。

## 完了条件
-   ZstdおよびLZ4で圧縮されたチャンクデータが正しく伸長される。
-   プロジェクトが正常にビルドできる。

## 参考 (C++)
-   `mcap/reader.hpp` の `LZ4Reader`, `ZStdReader`
