# タスク 3.2: `McapReader` クラスの実装 (コアロジック)

GitHub Issue: #12

## 概要
MCAPファイルの読み込みを行う `McapReader` クラスのコアロジックを実装します。ファイルを開き、ヘッダーとフッターを読み込む機能を実装します。

## 手順
1.  `Mcap.CSharp/Mcap/` ディレクトリ内に `McapReader.cs` ファイルを作成します。
2.  `McapReader` クラスを定義し、コンストラクタで `IReadable` のインスタンスを受け取るようにします。
3.  `Open()` メソッドを実装し、MCAPヘッダーとフッターを読み込み、基本的なファイル構造を解析します。
4.  `Header` および `Footer` プロパティを通じて、読み込んだヘッダーとフッター情報にアクセスできるようにします。

## 完了条件
-   `McapReader` クラスが定義され、基本的な読み込み操作のメソッドが実装されている。
-   MCAPファイルのヘッダーとフッターを読み込み、アクセスできる。
-   プロジェクトが正常にビルドできる。
