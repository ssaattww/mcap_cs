## MCAP データ型

MCAPでは、基本的なデータ型は以下のようにシリアライズ（バイト列に変換）されます。

### 固定幅整数 (Fixed-width types)

`uint16`, `uint32`, `uint64` などの多バイト整数は、**リトルエンディアン**のバイト順でシリアライズされます。

### 文字列 (String)

文字列は、まず `uint32` 型でバイト長を記録し、その後に有効なUTF-8でエンコードされた文字列データを続けます。

```
<uint32: バイト長><string: UTF-8データ>
```

### 配列 (Array)

配列は、まず `uint32` 型でシリアライズされた全要素の合計バイト長を記録し、その後にシリアライズされた各要素を続けます。

```
<uint32: バイト長><要素1><要素2>...
```

例えば、`uint64` の配列は以下のようになります。

```
<uint32: バイト長><uint64: 要素1><uint64: 要素2>...
```

### マップ (Map)

マップ（キーと値のペアの集合）は、まず `uint32` 型でシリアライズされた全エントリの合計バイト長を記録し、その後にシリアライズされたキーと値のペアを続けます。

```
<uint32: バイト長><キー1><値1><キー2><値2>...
```

例えば、キーと値が両方とも文字列のマップ (`Map<string, string>`) は以下のようにシリアライズされます。

```
<uint32: バイト長><string: キー1><string: 値1><string: キー2><string: 値2>...
```

### タイムスタンプ (Timestamp)

タイムスタンプは、`uint64` 型のナノ秒単位の時刻として表現されます。
