# タスク 4.3: READMEとサンプルコードの作成

GitHub Issue: #19

## 概要
C#ライブラリの使い方を示す `README.md` を作成し、基本的な読み書きの方法を示す簡単なサンプルコードを提供します。

## 手順
1.  `Mcap.CSharp` プロジェクトのルートディレクトリに `README.md` ファイルを作成します。
2.  `README.md` には、ライブラリの概要、インストール方法、基本的な使用例（MCAPファイルの書き込みと読み込み）、APIドキュメントへのリンクなどを記述します。
3.  `examples/` ディレクトリ（または適切な場所）に、MCAPファイルの書き込みと読み込みを行う簡単なC#サンプルコードを作成します。
4.  サンプルコードが動作することを確認し、`README.md` から参照できるようにします。

## 完了条件
-   `README.md` が作成され、ライブラリの基本的な情報と使用方法が記載されている。
-   動作するサンプルコードが提供されている。
-   プロジェクトが正常にビルドできる。
